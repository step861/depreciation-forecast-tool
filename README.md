# depreciation-forecast-tool
资产折旧摊销预测工具 - 固定资产折旧未来6年预测

一、操作步骤
导出EAS固定资产清单

二、折旧预测
双击打开工具，在浏览器中打开拖拽 Excel 文件到虚线区域，或点击区域选择文件
点击 "开始计算" 按钮，浏览器完成所有运算，计算完成后，页面显示相关结果，可点击 "下载结果 Excel" 按钮，生成的 Excel 包含多张工作表
从文件名中提取 YYYYMMDD 格式的日期，取月份作为账载期间，如果实际账载期间与文件名不一致，需手动修改。
例：文件名 集团固定资产清单20260717173117.xlsx → 默认账载期间为 2026年7月，如实际为6月，则手动修改。

三、注意事项	
1.文件名必须包含日期：格式为 YYYYMMDD，如 xx清单20260720xxxx.xlsx，否则无法解析期间，导出时默认文件名即可，不要修改
2.表头必须包含以下列：本年累计折旧、本期实提折旧额、固定资产科目，缺一不可【共享方案已设置好】
3.大文件处理：数万条记录时计算可能需要数秒，请耐心等待，不要关闭页面
使用权资产-房屋建筑物不参与预测
