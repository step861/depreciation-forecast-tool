计算规则

第一年折旧预测 = 本年累计折旧 + 月折旧额 × min(本年剩余月份, 剩余期间)
月折旧额：本期实提折旧额 > 0 时取本期实提折旧额；= 0 时取 (净额 − 预计净残值) ÷ 剩余期间；净额 ≤ 0 时月折旧额 = 0（避免因减值/负数产生负折旧）
本年剩余月份：本期实提折旧额 > 0 → 12 − 期间月；= 0 → 13 − 期间月
剩余期间 ≤ 0 且 本期实提折旧额 = 0 的资产：不参与未来月份模拟；若本年累计折旧 > 0，第一年取本年累计折旧（对齐EAS逻辑）；若本年累计折旧 = 0，所有年份均为 0
账载所属期间：从文件名自动识别，可手动修改，格式为 YYYYMM（如 202607）
使用权资产-房屋建筑物（科目 1611.01）：不参与折旧模拟，计算时自动过滤
